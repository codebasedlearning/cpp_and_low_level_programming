# Unit 0x03 - Born and Buried

An object is just its bytes - plus a promise to clean up. This unit follows an object through its life: what it is in
memory, how a constructor gives its bytes a meaning, what happens when it is copied, and when exactly its destructor
runs - at the closing brace, at the semicolon, or on the way of an exception. And how a class is split into a header
and a source file, once a program gets bigger.
